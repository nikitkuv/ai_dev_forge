# Диаграммы сценариев AI Development Forge — дизайн

## Цель

Создать три автономные HTML-диаграммы, которые наглядно объясняют описанные в `scenarios/` рабочие пути фреймворка.

## Исходные материалы

- `scenarios/01-new-project.md` — bootstrap нового проекта.
- `scenarios/02-existing-project.md` — bootstrap существующего проекта.
- `scenarios/03-development-pipeline.md` — полный цикл разработки Epic и TASK.

## Результат

Рядом с исходниками появятся три файла:

- `scenarios/01-new-project-diagram.html`
- `scenarios/02-existing-project-diagram.html`
- `scenarios/03-development-pipeline-diagram.html`

Каждый файл открывается локально в браузере, без CDN, сборки и сторонних зависимостей.

## Информационная модель

Диаграмма показывает последовательность основных этапов, документы и состояния, которые возникают на каждом этапе, а также обязательные ручные подтверждения. Альтернативные ветви (например, доработка, replan, возврат из review/testing) обозначаются пунктирными связями. Детальные диалоги и повторяющиеся примеры из Markdown в схему не переносятся дословно: они сворачиваются в короткие смысловые подписи.

## Визуальный язык

- Этапы: светлые карточки на временной оси.
- Пользовательские gates: контрастные янтарные ромбы/метки «Требуется подтверждение».
- Артефакты и canonical-документы: синие метки документов.
- Рабочие состояния и роли: цветные компактные метки.
- Основной поток: сплошные стрелки; исключения и циклы: пунктир.

Для трёх файлов используется общий каркас и разный акцентный цвет. В сценарии 3 основная диаграмма — жизненный цикл TASK с видимыми возвратами, а дополнительные рабочие ветви свёрнуты в отдельные блоки. Страница адаптируется для узкого экрана, доступна с клавиатуры и отключает анимацию при `prefers-reduced-motion`.

## Проверка

Проверить, что все три HTML-файла существуют, не ссылаются на внешние ресурсы, содержат корректные заголовки и открываются как локальные документы.
