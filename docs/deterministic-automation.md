# Детерминированная автоматизация Forge

Исходный framework bundle не является проектом-потребителем; проверки lifecycle выполняются на изолированных fixtures.

## Операции helpers

| Участок | Команды | Механическая работа | Что остаётся суждением |
| --- | --- | --- | --- |
| Контекст | context, section, query, index, budget | Metadata, извлечение разделов, поиск, оценка объёма | Выбор релевантных источников |
| Идентификаторы | next-id, inv-create, backlog add-bug | Максимум номера, создание INV/BUG | Содержание и необходимость записи |
| Валидация | validate | Схема, часть ссылок, статусы, adapters | Семантика требований и полнота evidence |
| Evidence | fingerprint, evidence-check, review-packet | Хеши, свежесть, diff, сборка пакета | Классификация production, риски, качество review |
| Проверки | checks-new, checks | argv, запуск, timeout, логи, проверяемый reuse | Какие проверки достаточны |
| Lifecycle | transition, epic-start/complete, accept-record | Запись переданных решений с rollback | Авторизация и приёмка |
| Backlog | update-row, archive-row/all, stale-rows | Ячейки, архивирование, Git-давность | Приоритет и решение закрыть работу |
| Git | commit-scoped | Ограниченный staging/commit | Смысл изменений и разрешение |
| Платформы | adapters, migrate, role | Генерация, обновление, transport и preflight | Planner/reviewer вызывают модель |
| Метрики | metrics-record, metrics | Запись и агрегация наблюдений | Интерпретация usage |
| Записи | identity-check, records-write, links-repair, records-recover | Сверка ID, пакетная запись, ремонт ссылок, восстановление журнала | Содержание и необходимость правок |

## Что предотвращает ошибки ID

1. Модель готовит содержание с символами `{{id:first}}`, а не копирует очередные номера.
2. Одна операция подставляет номера в имена файлов, frontmatter, заголовки, зависимости и план.
3. Сохранённая другой сессией запись инвалидирует preview. Повторный `next-id` номер не резервирует.
4. После записи проверяется согласованность; при ошибке восстанавливаются прежние файлы.
5. Восстановление сессии потребляет готовую диагностику.

Система проверяет объявленные структурированные поля и простые inline Markdown-ссылки. ID требований FR/NFR/BR и локальные AC/TC — другие пространства имён. Полного семантического анализа или автоматического выбора «правильного» ID нет.

## Границы

Helpers закрывают механические операции; суждение, авторизация и приёмка остаются за моделью и пользователем. Повторяющаяся ошибка оформляется как воспроизводимый случай: regression test для механики, точечная правка нейтральной инструкции для суждения. Evals и автоматический CI-triage не входят в bundle.
